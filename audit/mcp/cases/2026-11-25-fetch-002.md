## 源码审查（读的是 wheel 里解出来的代码）

五道防线，逐条有出处：

1. **每请求钩子**：`_refuse_private_destination`（server.py:184）解析 `raw_host`（ASCII/IDNA 形式，避免 Unicode 重编码到另一个名字）后逐地址判定。
2. **地址分类**：`_is_public_address`（server.py:155）先按 `_PUBLIC_EXCEPTIONS` 放行，再查 `_NON_PUBLIC_NETWORKS`（含 127.0.0.0/8、169.254.0.0/16、10/8、172.16/12、192.168/16、**100.64/10（阿里云 100.100.100.200）**、::/96、fc00::/7、fe80::/10 等），IPv4-mapped/NAT64 按内层 IPv4 判，其余 IPv6 必须在 2000::/3。
3. **连接期复核**：`_refuse_private_addresses`（server.py:213）由 `pin_direct_connections` 在**实际连接时**用解析结果再判一次，并只连被检查过的地址（注释引 #5557）——这一条正是防 DNS rebinding / TOCTOU 的做法。
4. **重定向**：httpx 的 request hook 对每一跳都执行；且见 `_open_stream`（server.py:542 起）自行处理 redirect、不交给 httpx 的 follow_redirects。
5. **默认值**：`allow_private_ips: bool = False`（server.py:431/765/852/997/1148/1174），即默认拒绝私网；`--allowed-hosts` 另有独立白名单钩子（allowlist.py）。
